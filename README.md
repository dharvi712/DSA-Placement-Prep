# DSA Placement Prep (Python)

Daily Data Structures & Algorithms practice, from basics to advanced,
prepping for placements. 1–2 hrs/day.

Python Basics → Arrays & Strings → Searching & Sorting → Recursion &
Backtracking → Linked Lists → Stacks & Queues → Trees & BSTs → Graphs →
Dynamic Programming → Greedy → Tries & Heaps → Revision

## How I work each problem

1. Copy `templates/solution_template.py` into the topic folder.
2. Rename it `NN_problem_name.py`.
3. Fill in approach + time/space complexity comments BEFORE coding
   (forces me to think first).
4. Write the solution + test cases.
5. Update the progress table below.
6. Commit with a clear message (see commit convention below).

## Commit message convention

```
[Topic] Problem name - status

Examples:
[Arrays] Two Sum - solved (O(n) hashmap approach)
[Recursion] Subsets - solved (backtracking)
[Python Basics] Session 1 - notes + practice
```
